# ZONE — سرور آنلاین

بدون نصب هیچ پکیجی کار می‌کنه (فقط Node.js نسخه ۱۸ یا بالاتر). همین سرور خودِ بازی را هم سرو می‌کنه، پس فقط یک جا باید دیپلوی بشه.

## فایل‌ها (همه کنار هم، بیرون از پوشه‌ها، به‌جز index.html)
- `server.js` — سرور
- `package.json`
- `rifle.js` — مدل سه‌بعدی اسنایپر (اگه نباشه بازی با اسنایپر ساده‌ی قبلی کار می‌کنه)
- `public/index.html` — خود بازی

## تست روی کامپیوتر
```
node server.js
```
بعد `http://localhost:3000` را باز کن.

## آنلاین کردن (Render)
۱) فایل‌ها را روی گیت‌هاب بگذار (`rifle.js` هم کنار `server.js`).  
۲) روی render.com یک Web Service بساز: Start Command = `node server.js`، Instance = Free.  
۳) آدرس `.onrender.com` را برای دوستات بفرست.

## نکته‌ها
- هر «کد اتاق» یک اتاق جداست (تا ۱۶ نفر).
- حالت‌های آنلاین: دث‌مچ، و بتل رویال آنلاین (لابی، شروع هم‌زمان، اسکواد).
- نسخه‌ی رایگان Render بعد از بی‌کاری می‌خوابه و اولین باز کردن ~۳۰ ثانیه طول می‌کشه.
- برخورد گلوله را هر بازیکن خودش حساب می‌کنه؛ جلوی تقلب گرفته نشده.
