# ZONE — سرور آنلاین

بدون نصب هیچ پکیجی کار می‌کنه (فقط Node.js نسخه ۱۸ یا بالاتر). همین سرور خودِ بازی (`public/index.html`) رو هم سرو می‌کنه، پس فقط یک جا باید دیپلوی بشه.

## تست روی کامپیوتر خودت
```
node server.js
```
بعد تو دو تب مرورگر `http://localhost:3000` رو باز کن، «آنلاین (دث‌مچ)» رو بزن و شروع کن.

## آنلاین کردن برای دوستان (Render، رایگان)
1. یه ریپوی جدید تو گیت‌هاب بساز و **محتویات** پوشه‌ی `zone-server` (فایل‌های `server.js`، `package.json` و پوشه‌ی `public`) رو آپلود کن.
2. تو render.com با گیت‌هاب وارد شو. **New → Web Service** رو بزن و ریپو رو انتخاب کن.
3. تنظیمات: Region = نزدیک‌ترین به خودتون، Runtime = **Node**، Build Command = خالی، Start Command = `node server.js`، Instance Type = **Free**.
4. **Create Web Service** رو بزن. وقتی نوشت «Live»، آدرس بالای صفحه (مثل `https://zone-xxxx.onrender.com`) رو کپی کن.
5. اون آدرس رو برای دوستات بفرست. همه اون رو باز می‌کنن، اسم‌شون رو می‌نویسن، «آنلاین (دث‌مچ)» رو می‌زنن و «ادامه / شروع».

نکته‌ها:
- نسخه‌ی رایگان Render بعد از چند دقیقه بی‌کاری می‌خوابه و اولین باز کردن حدود ۳۰ ثانیه طول می‌کشه.
- اگه بازی رو جای دیگه‌ای هاست کردی، تو منو تو کادر «آدرس سرور» بنویس `wss://zone-xxxx.onrender.com`.

## تنظیمات سرور
- `PORT` شماره‌ی پورت (پیش‌فرض 3000)
- `MAX_PLAYERS` حداکثر بازیکن هم‌زمان (پیش‌فرض 16)

## محدودیت‌ها
- فقط حالت دث‌مچ آنلاینه. بتل رویال هنوز آنلاین نیست.
- برخورد گلوله رو هر بازیکن خودش حساب می‌کنه، پس جلوی تقلب گرفته نشده.
